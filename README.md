# FirmaScope

Agentic due-diligence app for Polish companies, powered by [PBI-MCP](https://github.com/neflingcreations/PBI-MCP).

> Status: early build. Full README (architecture, eval results, demo instructions) lands in Phase 11 — see `CLAUDE.md` for the phase plan.

## Quickstart

```bash
npm install
npm run dev
```

No API keys required — demo mode replays recorded registry data and a real, previously-generated LLM brief.
